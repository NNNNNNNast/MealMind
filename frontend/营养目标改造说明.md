## 📋 需要修改的文件

### 1. status.js - 数据结构和方法

#### 修改 1：更新 formData 数据结构（第 63-76 行）

**原代码：**
```javascript
formData: {
  // ... 其他字段
  nutritionGoal: ''
}
```

**修改为：**
```javascript
formData: {
  // ... 其他字段
  calorieGoal: 1800,    // 卡路里目标（大卡）
  carbGoal: 200,        // 碳水目标（克）
  proteinGoal: 60,      // 蛋白质目标（克）
  fatGoal: 60           // 脂肪目标（克）
}
```

#### 修改 2：更新 saveHealthProfile 方法中的数据组装（第 240-261 行）

**原代码：**
```javascript
const healthData = {
  // ... 其他字段
  nutritionGoal: formData.nutritionGoal || ''
};
```

**修改为：**
```javascript
const healthData = {
  // ... 其他字段
  calorieGoal: formData.calorieGoal || 1800,
  carbGoal: formData.carbGoal || 200,
  proteinGoal: formData.proteinGoal || 60,
  fatGoal: formData.fatGoal || 60
};
```

#### 修改 3：更新 fillHealthForm 方法中的数据回填（第 320-340 行）

**原代码：**
```javascript
this.setData({
  // ... 其他字段
  'formData.nutritionGoal': profile.nutritionGoal || ''
});
```

**修改为：**
```javascript
this.setData({
  // ... 其他字段
  'formData.calorieGoal': profile.calorieGoal || 1800,
  'formData.carbGoal': profile.carbGoal || 200,
  'formData.proteinGoal': profile.proteinGoal || 60,
  'formData.fatGoal': profile.fatGoal || 60
});
```

#### 修改 4：删除 onNutritionGoalInput 方法，添加 4 个新的输入方法

**删除：**
```javascript
onNutritionGoalInput(e) {
  const value = e.detail.value;
  this.setData({ 'formData.nutritionGoal': value });
},
```

**添加：**
```javascript
// 营养目标输入处理
onCalorieGoalInput(e) {
  const value = parseInt(e.detail.value) || 0;
  this.setData({ 'formData.calorieGoal': value });
},

onCarbGoalInput(e) {
  const value = parseInt(e.detail.value) || 0;
  this.setData({ 'formData.carbGoal': value });
},

onProteinGoalInput(e) {
  const value = parseInt(e.detail.value) || 0;
  this.setData({ 'formData.proteinGoal': value });
},

onFatGoalInput(e) {
  const value = parseInt(e.detail.value) || 0;
  this.setData({ 'formData.fatGoal': value });
},
```
