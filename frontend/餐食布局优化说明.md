# 餐食布局优化说明

## 🎯 优化目标
将 4 个独立的餐食卡片合并成一个紧凑的卡片，减少页面长度，提升美观度。

## 🎨 设计特点

### 1. 空间优化
- **优化前：** 4 个独立卡片，总高度约 1200rpx
- **优化后：** 1 个合并卡片，总高度约 600rpx
- **节省：** 约 50% 空间

### 2. 视觉优化
- 使用 4 列网格布局，一目了然
- 统一的视觉风格
- 点击区域更大，操作更方便

### 3. 交互优化
- 点击任意餐食项即可记录
- 右上角"+"号提示可添加
- 食物列表自动展开/收起

### 4. 信息层次
- **第一层：** 卡片标题 + 总摄入
- **第二层：** 4 个餐食概览（图标 + 名称 + 热量）
- **第三层：** 详细食物列表（仅在有食物时显示）

---

## 📱 响应式设计

网格布局自动适配不同屏幕宽度：
```css
.meals-grid {
  display: grid;
  grid-template-columns: repeat(4, 1fr);
  gap: 20rpx;
}
```

在小屏幕设备上会自动调整间距和字体大小。
