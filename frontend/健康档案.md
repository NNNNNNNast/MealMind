# 健康档案开发文档

## 一、数据库表结构

```sql
CREATE TABLE `health_profile` (
    -- ========== 主键与关联 ==========
    `profile_id` INT NOT NULL AUTO_INCREMENT COMMENT '档案 ID',
    `user_id` INT NOT NULL COMMENT '用户 ID',
    
    -- ========== 核心字段（必填） ==========
    `age` INT NOT NULL COMMENT '年龄',
    `gender` TINYINT NOT NULL DEFAULT 0 COMMENT '性别：1-男，2-女，0-未知',
    `height` DECIMAL(5,2) NOT NULL COMMENT '身高 (cm)',
    `weight` DECIMAL(5,2) NOT NULL COMMENT '体重 (kg)',
    `diet_goal` VARCHAR(255) NOT NULL COMMENT '饮食目标',
    `taste_preference` TEXT NOT NULL COMMENT '口味/偏好描述',
    `avoid_foods` TEXT NOT NULL COMMENT '忌口/过敏描述',
    
    -- ========== 可选字段 ==========
    `chronic_disease` TEXT NULL COMMENT '慢性病描述',
    `smoking_status` TINYINT NULL DEFAULT 0 COMMENT '吸烟状态：0-不吸，1-吸烟',
    `exercise_frequency` VARCHAR(50) NULL COMMENT '运动频率',
    `systolic_bp` INT NULL COMMENT '收缩压 (mmHg)',
    `diastolic_bp` INT NULL COMMENT '舒张压 (mmHg)',
    `fasting_glucose` DECIMAL(4,2) NULL COMMENT '空腹血糖 (mmol/L)',
    `nutrition_goal` TEXT NULL COMMENT '营养目标',
    
    -- ========== 旧字段保留（兼容） ==========
    `diet_preference` JSON NULL COMMENT '【已废弃】',
    `health_tags` JSON NULL COMMENT '【已废弃】',
    `restrictions` TEXT NULL COMMENT '【已废弃】',
    
    -- ========== 派生字段 ==========
    `bmi` DECIMAL(4,1) GENERATED ALWAYS AS (
        ROUND(weight / ((height / 100) * (height / 100)), 1)
    ) STORED COMMENT 'BMI 指数',
    `weight_status` TINYINT GENERATED ALWAYS AS (
        CASE
            WHEN bmi < 18.5 THEN 1
            WHEN bmi < 24 THEN 2
            WHEN bmi < 28 THEN 3
            ELSE 4
        END
    ) STORED COMMENT '1-过低 2-正常 3-超重 4-肥胖',
    `tdee` INT GENERATED ALWAYS AS (
        ROUND(
            CASE gender
                WHEN 1 THEN 88.362 + (13.397 * weight) + (4.799 * height) - (5.677 * age)
                WHEN 2 THEN 447.593 + (9.247 * weight) + (3.098 * height) - (4.330 * age)
                ELSE 447.593 + (9.247 * weight) + (3.098 * height) - (4.330 * age)
            END
        )
    ) STORED COMMENT '基础代谢率 (kcal/天)',
    
    -- ========== 时间戳 ==========
    `created_at` TIMESTAMP NULL DEFAULT CURRENT_TIMESTAMP,
    `updated_at` TIMESTAMP NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    
    -- ========== 索引 ==========
    PRIMARY KEY (`profile_id`),
    UNIQUE INDEX `uk_user_id` (`user_id`),
    INDEX `idx_bmi` (`bmi`),
    INDEX `idx_weight_status` (`weight_status`),
    
    -- ========== 外键 ==========
    CONSTRAINT `fk_health_profile_user` FOREIGN KEY (`user_id`) 
        REFERENCES `users` (`user_id`) ON DELETE CASCADE
) ENGINE = InnoDB DEFAULT CHARSET = utf8mb4 COMMENT = '用户健康档案表';
```

**组件说明**：

| 分组 | 字段 | 组件类型 | 快捷模板 | 验证规则 | 说明 |
|------|------|----------|----------|----------|------|
| 身体基础 | age | InputNumber | 无 | 1-120，整数 | 用于计算基础代谢率 |
| 身体基础 | gender | RadioGroup | 无 | 必选一项 | 1-男，2-女，0-未知 |
| 身体基础 | height | InputNumber | 无 | 50-250，保留 1 位小数 | 单位：cm |
| 身体基础 | weight | InputNumber | 无 | 10-300，保留 1 位小数 | 单位：kg |
| 身体基础 | bmi | 自动计算 | 无 | 无 | 实时显示 BMI 和体重状况 |
| 饮食偏好 | dietGoal | Input | 5 个快捷按钮 | 不能为空 | 饮食目标 |
| 饮食偏好 | tastePreference | TagSelect | 6 个标签 | 至少选 1 个 | 口味偏好，多选 |
| 饮食偏好 | avoidFoods | Textarea | 无 | 不能为空 | 忌口/过敏信息 |
| 健康习惯 | chronicDisease | Textarea | 无 | 可选 | 慢性病描述 |
| 健康习惯 | smokingStatus | RadioGroup | 无 | 可选 | 0-不吸，1-吸烟 |
| 健康习惯 | exerciseFrequency | Input | 4 个快捷按钮 | 可选 | 运动频率 |
| 体检数据 | systolicBp | InputNumber | 无 | 70-250 | 单位：mmHg |
| 体检数据 | diastolicBp | InputNumber | 无 | 40-150 | 单位：mmHg |
| 体检数据 | fastingGlucose | InputNumber | 无 | 1.0-30.0 | 单位：mmol/L |
| 营养目标 | nutritionGoal | Textarea | 无 | 可选 | 营养目标描述 |

## 六、字段说明文案（前端使用）

| 字段      | Tooltip 文案                                               |
| --------- | --------------------------------------------------------- |
| 年龄      | 用于计算基础代谢率，不同年龄的营养需求不同                |
| 身高      | 单位：厘米 (cm)，用于计算 BMI 和基础代谢率                   |
| 体重      | 单位：公斤 (kg)，用于计算 BMI 和基础代谢率                   |
| 饮食目标  | 写得越具体，AI 推荐越精准。例如：3 个月减 10 斤、增肌练出腹肌 |
| 口味偏好  | 描述你喜欢的口味，AI 会优先推荐符合的食谱                 |
| 忌口/过敏 | AI 会完全避开你填写的食物，请如实填写                      |
| 慢性病    | 如有医生诊断的慢性病请填写，AI 会应用相应的饮食原则        |
| 吸烟状态  | 吸烟会影响维生素 C 等营养素的推荐量                         |
| 运动频率  | 用于计算每日总热量消耗，写得越详细越好                    |
| 血压/血糖 | 填写后 AI 会应用控盐/控糖等饮食原则                         |
| 营养目标  | 不填的话，AI 会根据你的基础信息自动推荐目标值              |

## 七、数据校验规则汇总

| 字段             | 校验规则              | 错误提示                   |
| ---------------- | --------------------- | -------------------------- |
| age              | 1-120，整数           | 请输入 1-120 之间的年龄      |
| gender           | 0、1 或 2              | 请选择性别                 |
| height           | 50-250，最多 1 位小数   | 请输入 50-250 之间的身高     |
| weight           | 10-300，最多 1 位小数   | 请输入 10-300 之间的体重     |
| dietGoal         | 不能为空，最大 255 字符 | 请填写饮食目标             |
| tastePreference  | 至少选择 1 个标签        | 请选择口味偏好             |
| avoidFoods       | 不能为空              | 请填写忌口/过敏信息        |
| systolicBp       | 70-250                | 请输入 70-250 之间的收缩压   |
| diastolicBp      | 40-150                | 请输入 40-150 之间的舒张压   |
| fastingGlucose   | 1.0-30.0              | 请输入 1.0-30.0 之间的血糖值 |
