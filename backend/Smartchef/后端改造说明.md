### 5. 数据库迁移脚本

**文件：** `Smartchef/database/migration_health_profile.sql`

**执行步骤：**

```sql
-- 1. 删除旧字段
ALTER TABLE healthprofile DROP COLUMN diet_preference;
ALTER TABLE healthprofile DROP COLUMN health_tags;
ALTER TABLE healthprofile DROP COLUMN restrictions;

-- 2. 新增字段
ALTER TABLE healthprofile ADD COLUMN diet_goal VARCHAR(255) COMMENT '饮食目标' AFTER bmi;
ALTER TABLE healthprofile ADD COLUMN taste_preference TEXT COMMENT '口味偏好' AFTER diet_goal;
ALTER TABLE healthprofile ADD COLUMN avoid_foods TEXT COMMENT '忌口/过敏食物' AFTER taste_preference;
ALTER TABLE healthprofile ADD COLUMN chronic_disease TEXT COMMENT '慢性病' AFTER avoid_foods;
ALTER TABLE healthprofile ADD COLUMN smoking_status TINYINT COMMENT '吸烟状态 (0-不吸，1-吸烟)' AFTER chronic_disease;
ALTER TABLE healthprofile ADD COLUMN exercise_frequency VARCHAR(50) COMMENT '运动频率' AFTER smoking_status;
ALTER TABLE healthprofile ADD COLUMN systolic_bp INT COMMENT '收缩压 (mmHg)' AFTER exercise_frequency;
ALTER TABLE healthprofile ADD COLUMN diastolic_bp INT COMMENT '舒张压 (mmHg)' AFTER systolic_bp;
ALTER TABLE healthprofile ADD COLUMN fasting_glucose DECIMAL(4,2) COMMENT '空腹血糖 (mmol/L)' AFTER diastolic_bp;
ALTER TABLE healthprofile ADD COLUMN nutrition_goal TEXT COMMENT '营养目标' AFTER fasting_glucose;
```

## ⚠️ 注意事项

### 1. 数据兼容性

**旧数据处理：**
- 如果数据库中已有用户健康档案数据，需要先备份
- 旧字段 `diet_preference`、`health_tags`、`restrictions` 会被删除
- 如需迁移旧数据，请在删除前执行：

```sql
-- 数据迁移（可选）
UPDATE healthprofile 
SET taste_preference = diet_preference,
    avoid_foods = restrictions
WHERE diet_preference IS NOT NULL;
```

## 🐛 已知问题修复

### 问题 1：Lombok @Builder 注解冲突

**问题描述：** 使用 `@Builder` 注解时，字段顺序变更可能导致构建器方法异常。

**解决方案：** 移除 `@Builder` 注解，仅保留 `@Data`、`@NoArgsConstructor`、`@AllArgsConstructor`。

**影响范围：** 无影响，因为代码中未直接使用 Builder 模式创建 HealthProfile 对象。
